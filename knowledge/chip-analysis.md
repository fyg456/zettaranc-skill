# 筹码峰分析（杉哥筹码理论）

> 结合指南针（CompSight）筹码数据与 Z 哥 B1 策略的实战分析框架。
> 核心思想：**筹码峰不是预言走势，而是告诉你什么位置该做什么事。**

---

## 一、核心指标

### 1.1 集中度

```
集中度 < 5%   → 极度密集 → 主力高度控盘 ⭐
集中度 5-10%  → 中度密集 → 有主力但不算极端
集中度 10-20% → 较分散   → 市场合力型
集中度 > 20%  → 非常分散 → 无明显主力痕迹
```

**应用原则：**
- 集中度越低，主力成本越统一，一旦启动爆发力越强
- 但低集中度 + 高获利比例 = 风险极高（获利盘一砸就崩）
- **当集中度 < 5% 同时获利比例 > 90% → 按出货形态处理**

### 1.2 获利比例

```
获利比例 < 30%  → 大部分被套 → 抛压小但上行阻力大
获利比例 30-50% → 多空平衡
获利比例 50-70% → 多数获利但合理 ✅ 最佳操作区间
获利比例 70-90% → 获利盘偏重 ⚠️ 随时可能有人止盈
获利比例 > 90%  → 极度获利 ❌ 高危——主力一砸就雪崩
```

**Z哥铁律：** 获利比例 > 90% 的票，除非是主升浪刚启动，否则一律按出货形态处理，只卖不买。

### 1.3 成本区间（70% / 90%）

```
70%成本区间：主力核心持仓成本带
  - 下沿 = 强支撑（主力最后防线）
  - 上沿 = 第一压力位
  - 当前价在区间内 = 中位均衡，方向选择中

90%成本区间：全部持仓成本带
  - 下沿 = 极限支撑
  - 上沿 = 终极压力位
  - 突破90%上沿 → 上方真空区，无阻力
```

### 1.4 重合度

```
重合度高（>60%） → 筹码结构稳定，支撑/压力有效
重合度低（<40%） → 筹码换手不充分，信号不可靠，不以之决策
```

## 二、5 步实战分析法

### 第 1 步：看密集区在哪

找到 70% 和 90% 成本区间，尤其是 70% 密集区。这是主力的核心持仓成本带。

### 第 2 步：当前价和密集区的位置关系

```
情况A: 股价在密集区下方   ← 弱势，等放量突破
情况B: 股价在密集区内     ← 中位均衡，方向选择
情况C: 股价在密集区上方   ← 强势，但要看获利比例
情况D: 股价脱离密集区进入真空区 ← 方向已选择
```

### 第 3 步：判断"上方还有多少空间"

```
股价到70%上沿的距离 = 短期空间
股价到90%上沿的距离 = 中期空间

示例（通化金马）：
  70%上沿 25.61 - 当前24.70 = 0.91元（+3.7%空间）
  90%上沿 27.16 - 当前24.70 = 2.46元（+10%空间）
  结论：还有空间可做 ✅

示例（超声电子）：
  70%上沿 17.06 - 当前17.41 = 已突破（-0.35元）
  90%上沿 17.55 - 当前17.41 = 只剩0.14元（+0.8%）
  结论：上方几乎无空间 ⚠️
```

### 第 4 步：判断获利盘抛压

结合集中度和获利比例一起看：

| 基础数据 | 组合 | 判断 |
|---------|------|------|
| 低集中 + 高获利 | <5% + >90% | ❌ 高危出货形态 |
| 低集中 + 低获利 | <5% + <30% | ✅ 主力被套，反弹机会 |
| 中集中 + 中获利 | 5-15% + 50-70% | ✅ 良性上涨 |
| 高集中 + 高获利 | <5% + >90% | ❌ 一砸就崩 |
| 高分散 + 高获利 | >15% + >90% | ⚠️ 获利但没主力，随时回调 |

### 第 5 步：综合评级

```
✅ 健康   = 密集区内 + 获利50-70% + 集中度适中 + 有上方空间
⚠️ 观望   = 突破密集区 + 获利70-90% + 集中度极低或极高
❌ 危险   = 获利>90% + 集中度<5% + 距上方空间<1%
```

## 三、核心判断原则

### 原则 1：筹码峰是支撑，不是阻力

```
密集区下沿 = 强支撑（主力成本区）
密集区上沿 = 第一压力位
突破上沿后 = 上方真空区 = 连阻力都没有
```

### 原则 2：集中度越低，突破爆发力越强

```
3% 的集中度意味着主力成本在 1 块钱以内
一旦启动，追都追不上
```

### 原则 3：获利比例决定能不能买

```
50-70%  获利 = 安全区间，可以操作
70-90%  获利 = 只能低吸不能追高
> 90%   获利 = 只卖不买（除非你是第一天进的）
```

### 原则 4：重合度告诉你信号靠不靠谱

```
重合度 < 40% → 数据不可信，别以这个做决策
重合度 > 60% → 这个筹码峰是真的，参考价值很大
```

### 原则 5：最核心的一句

> 筹码峰不是预言走势，而是告诉你什么位置该做什么事。支撑位到了就考虑买，压力位到了就考虑卖，突破就追，跌破就跑。**不预测，只应对。**

## 四、与 Z哥 B1 策略的结合

### 筹码修正后的 B1 评分系统

在原有 B1 评分基础上，增加筹码峰权重分：

| 筹码条件 | 加分 | 说明 |
|---------|:----:|:-----|
| 集中度 5-15% | +5 | 主力成本适中 |
| 集中度 < 5% + 获利<70% | +10 | 高度控盘+安全 |
| 获利比例 50-70% | +5 | 合理区间 |
| 当前价在 70% 密集区内 | +5 | 中位均衡 |
| 距 70% 上沿空间 > 3% | +5 | 还有上涨空间 |
| 距 90% 上沿空间 > 5% | +5 | 中期空间充足 |
| 重合度 > 60% | +5 | 筹码结构可靠 |

### 筹码峰否决条件（一票否决）

```
获利比例 > 90% + 集中度 < 5%  → 不出手，等洗盘
当前价距 90% 上沿 < 1%         → 不上车，空间不够
重合度 < 40%                     → 不以筹码判断，以其他指标为主
```

## 五、实战案例库

### 案例 1：通化金马（000766）— 良性上涨 ✅

```
均成本 23.74 | 70%区间 20.85-25.61 集中度10.25%
90%区间 19.06-27.16 | 获利71% | 重合度59.42%

解读：
- 集中度10.25%中位密集 → 主力控盘但没到极端
- 获利71%合理 → 多数人赚钱但没到雪崩点
- 当前24.70在70%区间内 → 还有空间到25.61
- 距90%上沿27.16还有10% → 中期空间充足
- 结论：✅ 健康筹码结构，适合回调低吸
```

### 案例 2：超声电子（000823）— 极度密集+突破真空区 ⚠️

```
均成本 16.48 | 70%区间 15.78-17.06 集中度3.91%⭐
90%区间 15.62-17.55 | 获利93%⚠️ | 重合度67.57%

解读：
- 集中度3.91%极高度密集 → 主力高度控盘
- 获利93%⚠️ → 几乎所有持仓者都在赚钱
- 当前17.41已突破70%上沿17.06 → 进入真空区
- 距90%上沿17.55只剩0.14元（+0.8%）
- 结论：⚠️ 控盘极高但获利盘极重，突破17.55才有空间，否则面临获利盘砸盘
```

### 案例 3：英威腾（002334）— 教科书级出货形态 ❌

```
均成本 8.88 | 70%区间 8.68-9.31 集中度3.54%⭐
获利98%⚠️⚠️ | 当前价9.47已突破70%上沿

解读：
- 集中度3.54%极度密集 → 主力高度控盘
- 获利98%⚠️⚠️⚠️ → 几乎100%的人在赚钱
- 当前已突破70%上沿 → 进入真空区
- 距90%上沿9.53只剩1.5%空间
- 结论：❌ 三重高危信号叠加，教科书级出货形态，不碰
```

## 六、常见误区

1. **误区：集中度越低越好 → 错！** 低集中 + 高获利 = 高危
2. **误区：获利比例高说明主力强 → 错！** 获利比例高说明随时有人要砸
3. **误区：筹码峰是静态的 → 错！** 每天交易都在改变筹码分布
4. **误区：只看一个指标就下结论 → 错！** 必须四个指标（集中度、获利、区间、重合度）综合判断
5. **误区：筹码分析万能 → 错！** 筹码再好也要结合大盘环境、技术指标一起看
